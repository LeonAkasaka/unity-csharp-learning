# 文字列リテラルと書式（補足）

このページは、[プリミティブ型と型変換](/unity-csharp-learning/csharp/primitive-types/) の補足です。`\` や `"` をそのまま書ける **逐語的文字列リテラル**（verbatim string literal）と **生文字列リテラル**（raw string literal）、文字列補間で数値の表示のしかたを決める **書式指定** と、表示の幅をそろえる **幅の指定** を学びます。

## 学習目標

このページを読み終えると、以下のことができるようになります。

- 逐語的文字列リテラル `@"..."` で、`\` を含む文字列を書ける
- 生文字列リテラル `"""..."""` で、`"` や改行を含む文字列を書ける
- 文字列補間の `{式:書式}` で、小数点以下の桁数や桁区切りを指定できる
- 文字列補間の `{式,幅}` で、表示の幅をそろえられる
- 文字列補間の中に、`{` と `}` そのものを書ける

## 前提知識

- [プリミティブ型と型変換](/unity-csharp-learning/csharp/primitive-types/) を読んでいること

---

## 1. エスケープシーケンスが増えると読みにくい

[プリミティブ型と型変換](/unity-csharp-learning/csharp/primitive-types/) で学んだように、文字列の中の `\` や `"` は、`\\` や `\"` のエスケープシーケンスで書きます。エスケープシーケンスが増えると、文字列の中身が読み取りにくくなります。

```csharp
Console.WriteLine("C:\\Users\\Alice\\Documents");
Console.WriteLine("{\"name\": \"Alice\", \"score\": 100}");
```

```
C:\Users\Alice\Documents
{"name": "Alice", "score": 100}
```

1 行目はファイルの場所（パス）、2 行目はデータをやり取りするときによく使う JSON 形式の文字列です。表示される文字列と、コードに書いた文字列の見た目が大きく違います。

---

## 2. 逐語的文字列リテラル

**書式：[逐語的文字列リテラル](https://learn.microsoft.com/dotnet/csharp/language-reference/tokens/verbatim)**
```
@"文字列"
```

文字列の前に `@` を付けると、`\` がエスケープシーケンスの始まりとして扱われなくなり、書いたとおりの文字になります。これを **逐語的文字列リテラル** といいます。

```csharp
Console.WriteLine(@"C:\Users\Alice\Documents");
Console.WriteLine(@"He said ""Hello"".");
Console.WriteLine(@"1行目
2行目");
```

```
C:\Users\Alice\Documents
He said "Hello".
1行目
2行目
```

逐語的文字列リテラルの中では、次のように書きます。

| 書きたい文字 | 書き方 |
|---|---|
| `\` | `\` のまま書く |
| `"` | `""` と 2 つ続けて書く |
| 改行 | ソースコードの中で、そのまま改行する |

`\n` などのエスケープシーケンスは使えません。`@"A\nB"` は、`A\nB` という 4 文字の文字列になります。パスのように `\` をたくさん含む文字列に向いています。

---

## 3. 生文字列リテラル

**書式：[生文字列リテラル](https://learn.microsoft.com/dotnet/csharp/language-reference/tokens/raw-string)**
```
"""文字列"""

"""
文字列の 1 行目
文字列の 2 行目
"""
```

`"` を 3 つ以上続けて囲んだ文字列を、**生文字列リテラル** といいます（C# 11 から）。中に書いた文字は、`\` も `"` も、そのまま文字列になります。

```csharp
Console.WriteLine("""He said "Hello".""");

string json = """
    {
        "name": "Alice",
        "score": 100
    }
    """;
Console.WriteLine(json);
```

```
He said "Hello".
{
    "name": "Alice",
    "score": 100
}
```

1 節の JSON と比べて、表示される文字列とコードの見た目が同じになりました。

複数行の生文字列リテラルには、次の決まりがあります。

| 決まり | 説明 |
|---|---|
| 開きの `"""` の後は、すぐに改行する | 文字列は、次の行から始まる |
| 閉じの `"""` は、行の最初に書く（前に空白があってもよい） | 最後の改行は、文字列に含まれない |
| 閉じの `"""` の前の空白の分だけ、各行の先頭の空白が取り除かれる | コードの字下げに合わせて書いても、字下げは文字列に含まれない |

上の例では、閉じの `"""` の前に空白が 4 つあります。そのため、各行の先頭から 4 つずつ空白が取り除かれ、`{` は行の先頭から表示されています。

文字列の中に `"""` を含めたいときは、囲む `"` の数を増やします。中に続けて書いた `"` の数より多ければ、いくつでもかまいません。

```csharp
Console.WriteLine(""""The delimiter is """."""");
```

```
The delimiter is """.
```

## 4. 書式指定

**書式：[文字列補間の書式指定](https://learn.microsoft.com/dotnet/csharp/language-reference/tokens/interpolated#structure-of-an-interpolated-string)**
```
$"{式:書式}"
```

[プリミティブ型と型変換](/unity-csharp-learning/csharp/primitive-types/) で学んだ文字列補間では、`{ }` の中の式の後ろに `:` と **書式指定子**（format specifier）を書くと、値の表示のしかたを決められます。

### 標準の書式指定子

よく使うものは、1 文字の記号と、桁数を表す数字で書けます。これを [標準の数値書式指定子](https://learn.microsoft.com/dotnet/standard/base-types/standard-numeric-format-strings) といいます。

| 書式指定子 | 意味 | 例 | 表示 |
|---|---|---|---|
| `F` と桁数 | 小数点以下の桁数を決める | `{1234.5678:F2}` | `1234.57` |
| `N` と桁数 | 桁区切りを付け、小数点以下の桁数を決める | `{1234.5678:N0}` | `1,235` |
| `D` と桁数 | 整数を、指定した桁数まで 0 で埋める（整数の値だけに使える） | `{42:D5}` | `00042` |
| `X` と桁数 | 16 進数で表示する | `{42:X2}` | `2A` |
| `B` と桁数 | 2 進数で表示する（.NET 8 から） | `{42:B8}` | `00101010` |
| `P` と桁数 | 100 倍して `%` を付ける | `{0.125:P1}` | `12.5%` |

```csharp
double price = 1234.5678;
int n = 42;
double rate = 0.125;

Console.WriteLine($"{price:F2}");
Console.WriteLine($"{price:N0}");
Console.WriteLine($"{price:N2}");
Console.WriteLine($"{n:D5}");
Console.WriteLine($"{n:X2}");
Console.WriteLine($"{n:B8}");
Console.WriteLine($"{rate:P1}");
```

実行結果の例です。小数点、桁区切り、`%` の書き方は、OS の地域の設定によって変わります。日本語や英語（米国）の設定では、次のようになります。

```
1234.57
1,235
1,234.57
00042
2A
00101010
12.5%
```

たとえば、地域の設定がドイツ語のときは、小数点が `,`、桁区切りが `.` になり、`{price:F2}` は `1234,57`、`{price:N0}` は `1.235`、`{rate:P1}` は `12,5 %` と表示されます。このページのこの後の実行結果も、日本語や英語（米国）の設定での例です。

`F2` や `N0` では、表示しきれない桁が丸められます。値そのものは変わらず、表示のしかただけが変わります。

丸め方は、四捨五入とは限りません。ちょうど中間の値は、偶数の側に丸められます。

```csharp
Console.WriteLine($"{0.5:F0} {1.5:F0} {2.5:F0} {3.5:F0}");
Console.WriteLine($"{0.125:F2} {0.375:F2}");
```

```
0 2 2 4
0.12 0.38
```

`2.5` は `2` と `3` のちょうど中間なので、偶数の `2` になります。[プリミティブ型と型変換](/unity-csharp-learning/csharp/primitive-types/) の `Math.Round` と同じ丸め方です。

### カスタムの書式指定子

`0` や `.` を並べて、表示の形を自分で決めることもできます。これを [カスタムの数値書式指定子](https://learn.microsoft.com/dotnet/standard/base-types/custom-numeric-format-strings) といいます。`0` は、その位置に数字を表示し、数字がなければ `0` を表示します。

```csharp
double price = 1234.5678;
int n = 42;

Console.WriteLine($"{price:0.00}");
Console.WriteLine($"{n:000}");
```

```
1234.57
042
```

`0.00` は「小数点以下を 2 桁で表示する」、`000` は「3 桁に満たない分を 0 で埋める」という意味です。

> 💡 **ポイント**: 同じ書式指定子は、[ToString メソッド](https://learn.microsoft.com/dotnet/api/system.double.tostring) の引数にも書けます。`price.ToString("F2")` は、`$"{price:F2}"` と同じ文字列になります。

## 5. 幅の指定

**書式：[文字列補間の幅の指定](https://learn.microsoft.com/dotnet/csharp/language-reference/tokens/interpolated#structure-of-an-interpolated-string)**
```
$"{式,幅}"
$"{式,幅:書式}"
```

| 要素 | 説明 |
|---|---|
| `幅` が正の数 | その文字数の幅で、右にそろえる。足りない分は、左に空白を入れる |
| `幅` が負の数 | その文字数の幅で、左にそろえる。足りない分は、右に空白を入れる |

`{ }` の中の式の後ろに `,` と数を書くと、表示の幅を決められます。値が幅より長いときは、切り詰めずにそのまま表示します。

```csharp
int n = 42;
double price = 1234.5678;

Console.WriteLine($"[{n,6}]");
Console.WriteLine($"[{n,-6}]");
Console.WriteLine($"[{price,10:F2}]");
```

```
[    42]
[42    ]
[   1234.57]
```

`{price,10:F2}` のように、幅と書式指定子は一緒に書けます。`,` の後に幅、`:` の後に書式指定子の順番です。

幅を決めると、表のように、行をまたいで位置をそろえられます。

```csharp
string[] names = { "Alice", "Bob", "Carol" };
int[] scores = { 100, 85, 7 };

for (int i = 0; i < names.Length; i++)
{
    Console.WriteLine($"{names[i],-6}|{scores[i],4}");
}
```

```
Alice | 100
Bob   |  85
Carol |   7
```

名前は左にそろえ、点数は右にそろえています。数値は右にそろえると、桁の位置がそろって読みやすくなります。

> 💡 **ポイント**: 幅は、文字の数で数えます。日本語の文字のように、半角の文字の 2 つ分の幅で表示される文字も 1 文字と数えるので、日本語を含む文字列では、表示の位置がそろわないことがあります。

## 6. { と } そのものを書く

文字列補間の中の `{` と `}` は、式を埋め込む場所の始まりと終わりを表します。`{` や `}` そのものを表示したいときは、`{{` と `}}` のように 2 つ続けて書きます。

```csharp
int n = 42;
Console.WriteLine($"{{n}} = {n}");
```

```
{n} = 42
```

`{{n}}` は `{n}` という文字列として表示され、`{n}` の部分には `n` の値が入ります。

文字列補間と逐語的文字列リテラルは、`$@"..."` のように組み合わせられます。

```csharp
string name = "Alice";
Console.WriteLine($@"C:\Users\{name}");
```

```
C:\Users\Alice
```

## よくあるミス

### 文字列の前の $ を忘れる

```csharp
string name = "Alice";
Console.WriteLine("こんにちは、{name} さん");
Console.WriteLine($"こんにちは、{name} さん");
```

```
こんにちは、{name} さん
こんにちは、Alice さん
```

`$` を付けないと、ふつうの文字列リテラルになり、`{name}` はそのまま表示されます。コンパイルエラーにならないので、実行して表示を見るまで気付きません。

### 小数の値に D を使う

```csharp
// ❌ NG: D は整数の値にしか使えない
// double price = 12.5;
// Console.WriteLine($"{price:D3}");  // FormatException
```

`D` は、整数の値を 0 で埋める書式指定子です。`double` の値に使うと、コンパイルエラーにはならずに、実行したときに `FormatException` が発生します。小数の値の桁をそろえるときは、`F` やカスタムの書式指定子 `000.0` などを使います。

### 生文字列リテラルの行を、閉じの """ より左に書く

```csharp
// ❌ NG: 2 行目の字下げが、閉じの """ より浅い
// string s = """
//   abc
//     """;  // CS8999
```

閉じの `"""` の前の空白が、各行から取り除かれる空白です。それより少ない空白で始まる行があると、取り除けないので、CS8999 のエラーになります。中身の行は、閉じの `"""` と同じか、それより深く字下げします。

## ワンポイントアドバイス

### 生文字列リテラルに値を埋め込む

生文字列リテラルの前に `$` を付けると、文字列補間を使えます。ただし、JSON のように `{` と `}` を含む文字列では、どれが式を埋め込む場所なのか区別できません。そのときは、`$` を 2 つ付けます。`$$` の生文字列リテラルでは、`{{式}}` が式を埋め込む場所になり、`{` と `}` を 1 つだけ書いたものは、そのまま文字になります。

```csharp
string name = "Alice";
int score = 100;

string json = $$"""
    { "name": "{{name}}", "score": {{score}} }
    """;
Console.WriteLine(json);
```

```
{ "name": "Alice", "score": 100 }
```

## まとめ

- 逐語的文字列リテラル `@"..."` では、`\` がそのままの文字になる。`"` は `""` と書く。パスのように `\` を多く含む文字列に向いている
- 生文字列リテラル `"""..."""` では、`\` も `"` もそのままの文字になる（C# 11 から）。複数行のときは、閉じの `"""` の前の空白が、各行の字下げとして取り除かれる
- 文字列補間の `{式:書式}` で表示のしかたを決める。`F2`（小数点以下 2 桁）、`N0`（桁区切り）、`D5`（0 で埋める）、`X2`（16 進数）などがある。ちょうど中間の値は、偶数の側に丸められる。小数点や桁区切りの記号は、OS の地域の設定で変わる
- 文字列補間の `{式,幅}` で表示の幅を決める。正の数は右そろえ、負の数は左そろえ。`{式,幅:書式}` と組み合わせられる
- `{` と `}` そのものは、`{{` と `}}` と書く

## 理解度チェック

1. 次のコードを実行すると何が出力されますか？

   ```csharp
   int a = 7;
   int b = 255;
   Console.WriteLine($"[{a,3}][{a,-3}]");
   Console.WriteLine($"{a:D3} {b:X2}");
   ```

2. `"C:\\Program Files\\App"` を、逐語的文字列リテラルで書き直してください。
3. `int score = 80;` のとき、文字列補間を使って `{score} は 80 点` と表示するには、どう書きますか？
4. 次のコードを実行すると何が出力されますか？ 行の先頭の空白の数にも注意してください。

   ```csharp
   string text = """
           A
             B
           """;
   Console.WriteLine(text);
   ```

<details markdown="1">
<summary>解答を見る</summary>

1. 次のように出力されます。`{a,3}` は右そろえ、`{a,-3}` は左そろえで、どちらも 3 文字の幅です。`{a:D3}` は 3 桁に 0 で埋め、`{b:X2}` は `255` を 16 進数で表示します。

   ```
   [  7][7  ]
   007 FF
   ```

2. `@"C:\Program Files\App"` です。
3. `$"{{score}} は {score} 点"` と書きます。
4. 次のように出力されます。閉じの `"""` の前の空白（8 つ）が各行から取り除かれるので、`A` は行の先頭から、`B` は空白 2 つの後に表示されます。

   ```
   A
     B
   ```

</details>

# 会話シーン

ゲームにおける会話・シナリオ表示の仕組みを実装するチュートリアルシリーズです。TextMesh Pro を使ったメッセージウィンドウの構築から、クリックで次のセリフへ進むページ送り、文字が流れるように表示される文字送りアニメーション、そしてキャラクター立ち絵の表示とフェード演出まで段階的に実装していきます。

## 学習のゴール

このセクションの内容を習得すると、以下のような機能を自力で実装できる水準を目指します。

- RPG やノベルゲームで一般的な会話シーンのメッセージウィンドウ
- クリックで次のセリフへ進むページ送り
- テキストが流れるように表示される文字送り演出
- アニメーションのスキップ機能
- キャラクター立ち絵の配置とフェードイン・フェードアウト演出

## 前提知識

- [Unity 基礎](/unity-csharp-learning/unity/) の内容（スクリプト・UI の基本操作）を理解していること
